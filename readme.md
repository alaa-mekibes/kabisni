## 🎯 كيف تلعب؟

|  #  | الخطوة                        | التفاصيل                                                                                |
| :-: | ----------------------------- | --------------------------------------------------------------------------------------- |
|  1  | 💥 **كبّس الشكل**             | كل ضغطة = نقطة واحدة + زمبيط                                                            |
|  2  | 🛒 **افتح المتجر**            | اشترِ أشكالاً، ألواناً، وحركات جديدة                                                    |
|  3  | 🦗 **اصمد أمام غزو الهورينغ** | من الثانية 50: حشرة كل ثانيتين، كل واحدة تلتهم نقطة/ثانية — اضغط عليها **مرتين** لقتلها |
|  4  | 👾 **اهزم الزعيم**            | بعد الغزو يظهر زعيم Voxel ثلاثي الأبعاد — يحتاج **20 ضربة**، وينفعل في المنتصف          |
|  5  | 💾 **احفظ تقدمك**             | زر الحفظ يُفتح بعد أول 10 ثوانٍ من اللعب                                                |

## ✨ المميزات

- 🆓 **مجانية 100%** — بدون حساب، اسم فقط والعب
- 🎨 **متجر كامل** — 8 أشكال × 10 ألوان × حركات مميزة، كلها تُفتح باللعب
- 🔊 **أجواء صوتية مولّدة برمجياً** — رياح، مطر، أمواج، رعد... بدون أي ملفات صوت
- 👁️ **مضاد للغش** — عدّاد نقرات، بصمة نتائج، وفخ لهنت المخصص للغشاشين
- 📱 **تعمل في كل مكان** — ملف واحد يُفتح مباشرة، أو على أي سيرفر ستاتيك
- 🌙 **صفحة غشاش مرعبة** — تأثير Glitch لمن يحاول الغش، تستحق المشاهدة... مرة واحدة 😈

<br>

## 🛠️ التقنية المستخدمة

| المكوّن         | التقنية                                                             |
| --------------- | ------------------------------------------------------------------- |
| البنية          | HTML + CSS + JavaScript خالص — بدون فريمورك، بدون أدوات بناء        |
| مرحلة الزعيم    | Three.js (r147) مضمّن محلياً                                        |
| باقي اللعبة     | 2D خفيفة بالكامل                                                    |
| الحفظ           | `localStorage` — تقدمك لا يغادر جهازك أبداً                         |

**للتجربة محلياً:**

```bash
python -m http.server
# ثم افتح: http://localhost:8000
```
